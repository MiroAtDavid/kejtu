# What Kejtu can do

These are supported features. Their availability in a conversation depends on
the selected model, saved permissions and installed runtimes. A description in
this guide is not confirmation that a service is connected.

| You want to…             | Kejtu can help with…                                                                         | What to check                                     |
| ------------------------ | -------------------------------------------------------------------------------------------- | ------------------------------------------------- |
| Think or write           | Conversation, explanations, drafting, code, diagrams and structured answers                  | Models                                            |
| Continue earlier work    | Search permitted conversation history and read exact originals; use a versioned notebook     | Notes; Permissions & recall                       |
| Remember people          | Inspectable people and relationship records with sources                                     | Permissions & recall → People                     |
| Find current information | Search and read web pages; interactive browsing through a configured browser MCP             | Web; Connections                                  |
| Work with local files    | Read, list, search, create, edit and move files in shared folders                            | Files and its installed runtime                   |
| Organize a project       | Projects, optional sections/modules, resources, tasks and a local calendar                   | Workspace; Files for resources                    |
| Read or make documents   | PDF, Word and Markdown readers/editors; conversational document work through available tools | Resources; writable folders; relevant connections |
| Learn from material      | Explain sources, practise one question at a time, give hints and discuss attempts            | Projects/Practice and readable source files       |
| Track your commitments   | Personal tasks, dates and open/done/cancelled states                                         | Personal tasks; task permission for chat          |
| Set a reminder           | Explicit reminders with schedules and local acknowledgement                                  | Permissions & recall; reminders controls          |
| Have research repeated   | Scheduled research with criteria, retained runs, reports and sources                         | Web; task permissions; Research in the sidebar      |
| Extend a workflow        | Reusable skills and MCP tools with explicit grants                                           | Skills; Connections                               |
| Use optional media       | Dedicated radio/video playback and widgets                                                   | Workspace; mpv and required local integrations    |

## Try requests like these

- “What did we decide about the outline last time? Find the original discussion.”
- “Remember that I prefer short meeting agendas.” Review any saved note afterward.
- “Find the official documentation for this library and explain the relevant part.”
- “Read the PDF in my shared project folder and explain the argument on page 3.”
- “Create a draft project plan in my writable working folder.”
- “Help me practise this material. Give me one question and wait for my answer.”
- “Add a personal task to finish the first draft on Friday.”
- “Research this topic every weekday, using these criteria, and retain a report.”

Ask for what you want in ordinary language. Kejtu should inspect relevant sources,
use available tools and explain any concrete missing permission or runtime. It
should report actual saved results rather than promise that a plan has been run.

Kejtu can make mistakes in reasoning, recall and tool use. Source links, exact
originals, tool activity and saved reports let you check important claims.
