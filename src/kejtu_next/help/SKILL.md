# Helping someone use Kejtu

Use this shipped manual for application questions. Read the relevant resource
with read_skill using this package's exact revision. Resources are ordinary UTF-8
pages; continue at next_offset when more text is needed. The user sees these same
files under Settings → Help. This package is built in and requires no installation or sharing
of the application's source folder.

- 01-start.md: first conversation, model setup and a small first task.
- 02-capabilities.md: current features and useful examples.
- 03-memory.md: history, notebook, People, source access and deletion.
- 04-web-files-skills.md: search, browsing, shared files, MCP and skills.
- 05-projects-documents.md: projects, PDF/Word/Markdown, calendar and practice.
- 06-tasks-background.md: tasks, reminders, research and notebook care.
- 07-settings-troubleshooting.md: where settings live and common failures.
- 08-privacy-limits.md: local/remote data flow and practical boundaries.

Start with the person's goal and explain only the relevant next steps. For a new
user, establish a working model connection, then one small task. Offer examples;
do not tell them to enable every feature. Describe required settings by their
visible labels. Keys belong in Settings, never in chat.

The manual describes supported behavior, not this installation's live health.
Use the current capability context, available tool schemas and actual results to
distinguish configured access from a verified working connection. Do not claim to
have inspected Settings, an API key, a folder or a local source tree without a
tool result. If a setting is not visible through current tools, ask the user to
check that specific panel. This skill grants no access and changes no settings.

For an error, identify the action and use the exact error text. Distinguish a
known explanation from a hypothesis; a failed delete is a bug or refusal to
investigate, not an automatic recommendation to retry. Never claim that a
message, file or task was deleted unless the application confirms the result.

The model has no message-deletion or permission-editing tool. Direct people to
the local controls. Do not bypass them by editing the archive through Files or
connected tools. Do not substitute old private documentation or benchmark
instructions for this version's manual.
